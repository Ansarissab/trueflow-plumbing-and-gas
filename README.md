# TrueFlow Plumbing & Gas

A modern, sleek single-page demo website for a fictional Brisbane plumbing and
gas business. Built as a portfolio showcase for Lachlan of
[KingTradie](https://kingtradie.com), using Astro (static output) and deployable
to Cloudflare Pages.

> This is a demo. TrueFlow Plumbing & Gas is not a real business, the reviews
> are fictional, and all credentials are placeholders.

## Quick start

Requirements: Node 20+ (this repo manages Node with [mise](https://mise.jdx.dev/)).

```bash
export PATH="$HOME/.local/share/mise/shims:$PATH"
npm install
npm run build      # outputs to dist/
npm run preview    # serve dist/ at http://localhost:4321
npm run dev        # dev server with HMR
```

Cloudflare Pages: build command `npm run build`, output directory `dist`.
No adapter is needed for fully static output.

## Deployment targets

- Tested with `astro.config.mjs` `site` set to a `*.pages.dev` placeholder so
  sitemap and canonical URLs resolve.
- All assets are referenced relatively, so the build drops straight into any
  static host.

## Design system

The whole design system lives in `src/styles/global.css` as design tokens:

- One ink navy family plus ice neutrals for surfaces and text.
- One brand blue family, one amber CTA family, one green success family and a
  red family reserved for problem states.
- Every colour outside the `:root` block is a `var()` or
  `rgba(var(--xxx-rgb), alpha)` reference, so no one-off hues can creep in.
- Type is Plus Jakarta Sans Variable throughout.
- Fully responsive with no horizontal overflow at any width, verified by an
  automated overflow scan plus manual checks.

## Copy structure

The site follows the StoryBrand PEACE narrative order:

1. Hero (empathy + same-day promise + twin CTAs)
2. Problems the customer faces (`Problems.astro`)
3. Services as solutions (`Services.astro`)
4. Trust and experience (`Guide.astro`)
5. Three-step plan and guarantee (`Plan.astro`)
6. Reviews (`Reviews.astro`)
7. FAQ (`Faq.astro`)
8. Contact and request-a-callback form (`Contact.astro`)

Copy rules: Australian English, no em dashes anywhere in rendered copy, en
dashes only for numeric ranges (Mon to Sat 6:30am to 7pm, prices), and curly
apostrophes.
